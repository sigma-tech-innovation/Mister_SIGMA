# Contributing

Ce dépôt est maintenu par Sigma Tech Innovation.

Les règles canoniques du projet sont définies dans
[`docs/governance/REGLES_CANONIQUES.md`](docs/governance/REGLES_CANONIQUES.md).

Résumé pour les contributeurs :

- travailler une tâche à la fois ;
- inspecter avant toute modification ;
- documenter chaque changement ;
- tester avant validation ;
- utiliser des commits clairs ;
- ne jamais publier de secret.
